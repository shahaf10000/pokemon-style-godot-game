# 🧩 Pokémon-Style 3D Game (Godot 4)

A 3D turn-based monster-battling game inspired by Pokémon Generation 9, built in [Godot 4](https://godotengine.org).  
This is a personal learning project to explore 3D game development, GDScript, and Godot's scene system.

---

## 🎯 Project Goals

- Build a fully playable 3D prototype in 1–2 months
- Learn and apply GDScript in a real project
- Implement:
  - Free movement in a 3D overworld
  - Dialog system with NPCs
  - Turn-based battle system with health, attacks, and win/lose logic
  - Scene transitions and basic game flow

---

## 🗂️ Project Structure

res://
├── scenes/ # Main game scenes (world, player, battle)
├── scripts/ # GDScript files for game logic
├── ui/ # Dialog boxes, battle UI, HUD elements
├── assets/ # Models, textures, sounds
├── data/ # JSON files for dialog or configs
└── main.tscn # Entry point for the game
